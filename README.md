# twiniGG

Twini Twin City is a Digital Twin and smart-city learning demo with a browser app, Flutter mobile client, and Unity WebGL integration point.

## Run the web app

```sh
python3 server.py
```

Open `http://localhost:8000` in a browser.

Admin users are stored locally in `data/admin-users.sqlite3`; that database is intentionally excluded from version control. Create an admin account on the device where the server runs.
